# LAB-2

## Programs

### 1. LinearSearch.py
Implements Linear Search to find an element in a list.

### 2. BinarySearch_sorted.py
Performs Binary Search on a sorted list.

### 3. BinarySearch_unsorted.py
Demonstrates searching in an unsorted list (typically by sorting first or using an alternative approach).

### 4. bubble.py
Implements Bubble Sort algorithm.

### 5. insertion.py
Implements Insertion Sort algorithm.

### 6. selection.py
Implements Selection Sort algorithm.
