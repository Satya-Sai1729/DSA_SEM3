# LAB-3

## Programs

### 1. bubble.py
Sorts a list of elements using the Bubble Sort algorithm by repeatedly comparing and swapping adjacent elements.

### 2. insertion.py
Sorts a list of elements using the Insertion Sort algorithm by inserting each element into its correct position.

### 3. selection.py
Sorts a list of elements using the Selection Sort algorithm by repeatedly selecting the minimum element from the unsorted portion.

### 4. merge.py
Sorts a list of elements using the Merge Sort algorithm based on the divide-and-conquer technique.

### 5. quick.py
Sorts a list of elements using the Quick Sort algorithm by selecting a pivot and partitioning the elements around it.

## Concepts Covered

- Sorting Algorithms
- Arrays / Lists
- Recursion
- Divide and Conquer
- Swapping
- Functions
- Time and Space Complexity

## Language

Python 3
